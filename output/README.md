Результаты прогона. Сюда программа пишет таблицу и картинки.

`lengths.csv` / `lengths.xlsx` — длины по листам.
`metrics.txt` — сколько времени, сколько раз ходили в API.
`llm_raw` — json модели, можно править и пересчитать без API.
`markup` — что вошло в сумму.
`overlays` — метки размеров на чертеже.
