# длина по изометриям

Скрипт берёт pdf с изометриями и считает длину трубы на листе. Ветки тоже. До ПОДКЛЮЧЕНИЕ и СМ, кусок один раз.

ИИ смотрит картинку и говорит какие цифры это длина. Складывает python. Сомнительное не угадываю, в таблице review.

Свою модель на этих 10 листах не учил: эталона мало, сумма считается кодом.

## что где лежит

`data` — исходные pdf с изометриями, их программа читает.
`web` — сайт-окно: вёрстка, стили, кнопка «Рассчитать».
`output` — результаты, папка на каждый PDF.
`.env` — ключи API, в git не кладётся. Образец: `.env.example`.

Код в корне: `app.py` открывает окно в браузере, `run.py` считает из консоли.

## длина

Беру участки по оси и ответвления.

Не беру вложенное (в примере 916 и 300 внутри 1950 и 840), общий габарит если уже есть куски, координаты X/Y/Z, DN, опоры, кружки позиций, штурвал.

Цифры из pdf, OCR не ставил.

Лист 7 LC_1040: 60+1950+650+840+522+250+34 = 4306, как в примере.

## как запустить

Нужен python 3.10+. Папка проекта `iso_length`. Pdf по умолчанию: `data\02_Изометрии_10_листов.pdf`.

Один раз ставишь окружение:

```
cd iso_length
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Ключи в `.env`, без кавычек и без пробела после `=`:

- Groq (бесплатно): https://console.groq.com/keys → `GROQ_API_KEY=gsk_...`
- OpenAI / Codex (платно): https://platform.openai.com/api-keys → `OPENAI_API_KEY=sk-...`

`.env` в git не клади.

### консоль, без браузера

```
python run.py
```

Чужой pdf: `python run.py "C:\путь\к\файлу.pdf"`
Только лист 7: `python run.py --pages 7`
Таблица из уже готовых json: `python run.py --from-json output\llm_raw`

На Groq два прохода на лист и пауза ~70 с между запросами. 10 листов это около 20–25 минут, не зависание. Если 429 — подожди минуту и запусти снова. Закрытые json (`locked`) второй раз не гоняет. Один проход: в `.env` `ISO_LLM_PASSES=1`.

## где лежит output

На каждый PDF своя папка: `output\имя_файла_без_расширения\`.

Пример: `output\02_Изометрии_10_листов\`

- `что_это.txt` — что за файл и какая сумма
- `lengths.xlsx` — ведомость: лист «сводка» и «длины», внизу итого
- `report.html` — то же в браузере, с картинками листов
- `markup\` — чертёж, зелёным что вошло в сумму
- `overlays\` — метки D1, D2
- `llm_raw\` — json модели, можно править руками

Другой PDF не затирает этот: у него будет соседняя папка.

`.env` с ключом в git не клади.

Чтобы только пересчитать суммы без API: `python run.py --from-json output\02_Изометрии_10_листов\llm_raw`

После модели код сам правит явное: Н.О., штурвал, изоляция, два числа в одной точке, длину рядом с Z+/X/Y не считает координатой, 2000 и 2400 на разных участках оба берёт. Если в json стоит `"locked": true` — этот лист не перезапишет ни API, ни автоправка. Убери locked, если хочешь отдать лист модели снова.
